## Overview

A simple web app that helps plant owners remember care schedules and get personalized advice for their plants.

## The Problem

Plant owners often forget:
- When they last watered their plants
- What specific care each plant needs
- Whether their plant looks healthy

## The Solution

Upload a photo of your plant, and the app:
- Identifies the plant using Claude Vision
- Suggests optimal watering schedules
- Provides care tips specific to that plant type
- Sends reminders when it's time to water

## Status

Currently in progress. Working on integrating Claude Vision API and building the reminder system.

## Tech Stack

- **Frontend:** Next.js, React
- **AI:** Claude Vision API for plant identification
- **Styling:** Tailwind CSS
- **Deployment:** Planned for Vercel

More updates coming soon as we build this out!
