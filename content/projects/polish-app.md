## Overview

After finishing Duolingo, I realized that simple vocabulary drilling wasn't translating to real language skills. I needed to learn Polish *in context*, so I built an interactive Polish learning app that uses Claude to generate contextual lessons.

## The Problem

Traditional language apps teach you words in isolation. Duolingo taught me Polish vocabulary, but I couldn't have a real conversation. The missing piece was *context* and *application*.

## The Solution

I built a web app that:
- Uses Claude API to generate contextual Polish lessons
- Provides interactive exercises
- Gives immediate feedback on your responses
- Adapts difficulty based on your progress

## What I Learned

1. **Claude API is powerful** - Being able to generate personalized content on demand changes what's possible
2. **Context matters** - Users learn better when language is tied to real scenarios
3. **Shipping matters more than perfect** - The app isn't perfect, but it's live and being used

## Tech Stack

- **Frontend:** Next.js, React, Tailwind CSS
- **Backend:** Claude API for content generation
- **Deployment:** Vercel

The code is open source on GitHub. If you're learning languages with AI, feel free to fork and adapt it!
